# Office Layout

テキストからオフィスの座席表を作る、小さな Web アプリです。名前や配置を編集すると図にすぐ反映され、PNG 画像として保存できます。

**[座席表を開く](https://oharato.github.io/office-layout/)**

## 使い方

1. 公開ページを開くと、名前入りの座席・空席・荷物置き場を含む26枠のサンプルが表示されます。
2. 「座席データ」の入力欄で名前や座標、サイズを変更します。
3. 「PNGで保存」を押すと、座席表を `office-layout.png` としてダウンロードできます。
4. 「サンプルに戻す」を押すと、入力内容を初期サンプルに置き換えます。

編集内容の自動保存はありません。ページを再読み込みするとサンプルに戻ります。編集を残す場合は入力テキストを別途保存してください。入力した座席データはブラウザー内で処理されます。

## 入力書式

1行につき1枠を、半角カンマ区切りで記述します。

```text
xの開始位置,yの開始位置,x方向の長さ,y方向の長さ,名前,文字の回転角度
```

```text
1,1,1,2,山田
1,3,1,2,鈴木
3,1,1,2,
5,1,1,4,荷物置き場,90
```

- 左上を `(1,1)` とし、右方向が x、下方向が y です。1マスは40pxです。
- 座標と長さには正の数を指定してください。
- 名前を空にすると空席になります。末尾のカンマは残してください。
- 回転角度は省略できます。`90` を指定すると文字が90度回転します（枠は回転しません）。
- 空行は無視されます。名前にカンマや改行は使えません。CSV の引用符によるエスケープには対応していません。
- 図の大きさは配置した枠の右端・下端に合わせて決まります。
- 不正な行は行番号付きで通知され、正しい行のみ描画します。PNG 保存前にすべての入力エラーを修正してください。
- PNG 保存は各辺8192px以内、総画素数16,777,216以内に制限しています。上限超過や画像生成の失敗は画面に表示されます。

初期サンプルを変更する場合は [textarea-data.js](textarea-data.js) の `sampleLayoutText` を編集します。

## ローカルで動かす

Node.js 24.15.0 以降の24系を推奨します。対応範囲は `package.json` の `engines.node` を参照してください。

```sh
npm ci
npm start
```

ブラウザーで **http://localhost:8080/index.html** を開きます。`/` は別の SSR サンプル（`abc` の1枠）です。

編集画面の Vue はバージョンと整合性ハッシュを固定した CDN から読み込むため、インターネット接続が必要です。Express サーバーは IP ごとに毎分120リクエストに制限しています。

## テストとセキュリティ

```sh
npm test
npx playwright install --with-deps chromium
npm run test:e2e
npm run audit
```

テストでは初期サンプル、入力とリセット、SSR、HTML エスケープ、レート制限、Vue の CDN URL と整合性ハッシュを確認します。

`test:e2e` は Chromium でサンプルを実際に PNG としてダウンロードし、ファイル形式・寸法、入力検証、画像サイズ上限、保存失敗時の通知を確認します。テスト中は CDN の代わりにインストール済みの同一 Vue ファイルを使います。

GitHub Actions でテスト・npm audit・CodeQL を実行します。Dependabot は npm と GitHub Actions の更新を週次で確認します。Vue を更新した際は `index.html` の CDN バージョンと SRI ハッシュも更新してください。不一致はテストで検出されます。

## GitHub Pages

このリポジトリは `master` ブランチのルートを GitHub Pages で静的配信します。変更をマージし、Pages のデプロイが完了すると公開ページに反映されます。Node.js サーバーやビルド処理は不要です。
